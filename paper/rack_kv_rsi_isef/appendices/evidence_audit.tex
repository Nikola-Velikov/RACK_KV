The source package distinguishes five evidence states:
\begin{itemize}[leftmargin=1.5em]
  \item \textbf{Verified}: supported directly by inspected source code or local artifacts.
  \item \textbf{Empirically observed}: measured in the evaluated cases but not elevated to a universal guarantee.
  \item \textbf{Provisional}: safe wording used for corpus-bounded novelty or incomplete evidence.
  \item \textbf{Planned}: an intended experiment or theorem, not a completed contribution.
  \item \textbf{Unresolved}: intentionally left without a factual claim.
\end{itemize}

The file \artifactpath{missing_evidence.json} records any remaining evidence gaps and whether the verified two-prompt 32-layer quality package is included in the paper-support materials.
