\section{Limitations}

The current theorem is local. It certifies the effect of skipping on one reconstructed attention computation for one query head and one query step. It does not certify compression error relative to the original cache, nor does it propagate through output projections, residual connections, later layers, or final token probabilities. The paper therefore establishes a rigorous result about one part of the approximation pipeline rather than an end-to-end guarantee for the language model.

The certificate is also conservative. That conservativeness is visible empirically in the low skip rate and is explained theoretically by the coarse geometric summaries, worst-case value norms, loose retained-mass lower bounds, and grouped-query sharing. A logical query-head skip does not yet imply physical KV-block omission, so the present implementation does not demonstrate decode avoidance, bandwidth reduction, or latency improvement.

The empirical evidence is intentionally narrower than the claims it would take to establish a complete inference system. The experiments use one model family, representative layers, and a full-model teacher-forced evaluation over only two short deterministic prompt categories. That end-to-end test is useful because it propagates the modified streams through all \(32\) layers, but it is still limited in prompt diversity, context length, and task variety. It does not replace broader prompt coverage, autoregressive generation studies, or validation on a second model family.

The project baselines labeled \enquote{-style} are source-inspired approximations rather than official reproductions, and the novelty statement is explicitly bounded to the verified frozen July 2026 corpus. These limitations do not negate the current results, but they define their scope: the paper shows that compression, independent random access, rigorous local skipping certification, and narrow full-model quality measurement can coexist in one design, not that all remaining quality and systems questions have been settled.
